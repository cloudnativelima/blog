Aquí reunimos las ideas y experiencias que nacen en nuestras comunidades. Puedes compartir una guía, un aprendizaje o una experiencia trabajando con tecnologías cloud native.

## Comparte lo que aprendiste

No necesitas tener todas las respuestas. Un problema que resolviste, una herramienta que probaste o una explicación que te ayudó pueden ser útiles para otra persona.

- Explica el contexto y el objetivo.
- Incluye pasos que otras personas puedan seguir.
- Añade enlaces a la documentación y reconoce las fuentes.

## Cómo contribuir

Los artículos se escriben en **Markdown** y se envían mediante un pull request al repositorio de la comunidad.

1. Copia la plantilla de `plantilla.md`.
2. Guarda tu artículo en `articulos/tu-articulo.md`.
3. Completa el título, resumen, autor, fecha y etiquetas.
4. Abre un pull request para que el equipo lo revise.

Consulta [la guía para contribuir](https://github.com/cloudnativelima/blog/blob/main/README.md) para conocer la estructura y probar tu artículo localmente.
